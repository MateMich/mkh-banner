Privacy policy

Last updated: 10 November 2026

MKH banner is a personal tool run by the owner of the YouTube channel Music Know How on their own computer.

What it accesses

Using the YouTube Data API, with the channel owner's permission, it reads the channel's public statistics (subscriber count) and uploads a new channel banner image.

What it stores

The authorization token and the last subscriber count are stored only on the owner's computer. No data is sent to any server other than YouTube / Google, and nothing is shared with or sold to third parties.

Other users

The tool does not access, collect or store data of any other user or viewer.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. MKH banner's use of information received from Google APIs adheres to the Google API Services User Data Policy.
